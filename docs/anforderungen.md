## 2. Kennzahlen und Geschäftslogik

| Thema | Wert |
|---|---|
| Google Ads | 10.000 €/Monat → 12.000 Kampagnen-Klicks → 80 % des Traffics |
| Performance Max | 1.000 €/Monat → 200 Filialanfahrten |
| Abschlussquote im Laden | 80–90 % |
| Margen | Schlafsysteme 80 %, Wasserbetten 50 %, Boxspring 20 % |
| Endgeräte | 70 % mobil, 10 % PC (restliche 20 % nicht genannt) |
| Verkaufslogik | Mit günstigen Matratzen werben, hochpreisige Matratzen verkaufen. Wer weiß, dass es etwas Günstiges gibt, kommt eher in den Laden und nimmt zumindest etwas mit – dort ist Upselling möglich |
| Suchverhalten | „Boxspring“ wird oft gesucht, auch wenn etwas anderes gemeint ist |
| Warum es uns gibt | „Riesen-Auswahl“: alle Ausprägungen an Betten und alle Preissegmente |

### 4.8 Mehrere Auftritte

Aktuell wird „aus allen Kanonen gefeuert“, das verwirrt Kunden. Beispiel: Ein Kunde sucht „Boxspring“, landet bei
Lohmühle und findet das Bettenhaus „Boxspringbetten.com“ nicht.

| Auftritt | Zielgruppe / Stand |
|---|---|
| gesunde-matratzen.de | Massenmarkt |
| boxspringbetten.com | Boxspring |
| pflege-betten.de | Neuer Auftritt |
| luxusbetten | Läuft nicht, es kommen kaum Kunden in den Laden |
| Lohmühle | OFFEN, siehe O6 |

Anforderung: Jeder Auftritt hat eine eigene Zielgruppe, eigene Kampagnen und einen eigenen Auftritt (ENTSCHIEDEN).
Umfang dieses Projekts (nur gesunde-matratzen.de oder weitere Auftritte): OFFEN.
